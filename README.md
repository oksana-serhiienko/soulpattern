# SoulPattern Legal

Static HTML pages for Vercel deployment.

- `index.html`
- `privacy-policy.html`
- `terms-of-use.html`

Upload these files to a GitHub repository and import it into Vercel. Choose the **Other** framework preset; no build command or output directory is needed.

Before publishing, verify the privacy statements against the actual app code and all integrated SDKs, especially whether any analytics/crash-reporting SDK is enabled and whether the date of birth remains entirely on-device. This is a draft, not legal advice.
